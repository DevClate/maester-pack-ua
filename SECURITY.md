# Security

Report a security problem in this pack privately, through
[GitHub's private vulnerability reporting](https://github.com/DevClate/maester-pack-ua/security/advisories/new),
not in a public issue. The same link is the pack's `SecurityContact` in `maester-pack.json`.

This pack only reads from Microsoft Graph: its manifest declares no tenant writes, network hosts or modules.

A problem in Maester itself goes to [maester365/maester](https://github.com/maester365/maester/security).
